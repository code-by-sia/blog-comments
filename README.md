# blog-comments

Discussion threads for [blog.siamand.cc](https://blog.siamand.cc/), via
[giscus](https://giscus.app/). Each post maps to one discussion in the
**Announcements** category; the comment box on a post writes here.

This repo holds no code. `giscus-theme.css` is the stylesheet giscus loads
inside its iframe so the comments match the blog's design.
